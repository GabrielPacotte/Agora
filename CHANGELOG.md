# Changelog

All notable changes to this project will be documented in this file.

The project follows semantic versioning.

---

## [0.1.0] – 2026-02-06

### Added
- Core domain model (users, posts, comments, stances, tags)
- PostgreSQL schema and SQL functions
- Repository and service layers
- Authentication (JWT access token + refresh token)
- HTTP API with versioned routes
- OpenAPI specification
- Technical documentation for contributors

### Notes
This is the first public release of Agora.
The focus is on architecture, foundations, and developer experience.
