# Testing Strategy

Agora prioritizes meaningful tests over superficial coverage metrics.

---

## What Is Tested

- Domain logic via unit tests
- Repositories via integration tests
- Services via mock-based tests

---

## What Is Not Tested (Yet)

- HTTP handlers (covered indirectly)
- Full end-to-end flows
- OpenAPI drift checks (planned)

---

## Philosophy

Tests should:
- Validate behavior, not implementation
- Fail loudly when invariants break
- Be easy to reason about

Some tests are intentionally heavy if they provide confidence.

---

## Running Tests

All tests can be run using:

go test ./...

Database-dependent tests require a local PostgreSQL instance.
