# HTTP Layer

The HTTP layer is a translation boundary.

It exists solely to adapt HTTP requests and responses to the internal application model.

---

## Responsibilities

Handlers are responsible for:
- Parsing inputs
- Validating request shape
- Mapping DTOs to domain inputs
- Calling services
- Mapping domain outputs to DTOs
- Returning standardized HTTP responses

---

## DTOs

DTOs are:
- Explicit
- Endpoint-specific
- Independent from domain models

They are allowed to evolve independently of the domain.

---

## Response Format

All responses follow a consistent structure:
- A data payload
- A meta object

Errors are standardized and mapped to appropriate HTTP status codes.

---

## Authentication

Authentication is handled via middleware.

Handlers access the authenticated user via the request context.
They do not parse or validate tokens directly.

---

## Rule of Thumb

If a handler exceeds reasonable complexity, logic likely belongs in a service.
